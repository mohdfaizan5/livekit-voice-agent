# Context

## Domain terms

- Teaching session: The lesson plan loaded for a live class, including title, topic, learning goals, and lesson structure.
- Learning goal: A concrete outcome the learner should achieve during a teaching session.
- Lesson phase: One stage in the teaching session flow, typically `warmup`, `concept`, `practice`, and `exit`.
- Lesson state: The runtime progress for the current teaching session, including phase order, current phase, covered goals, and remaining goals.
- Board document: The backend source of truth for structured content shown on the classroom display.
